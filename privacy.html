Privacy policy

Workspace MCP Servers is a personal tool used only by its owner on their own Google accounts.

  • What it accesses: Gmail messages, labels, filters and drafts in the owner's own accounts, through the Gmail API scopes the owner grants.
  • How it is used: to search, label, file, draft and clean up the owner's own mail at the owner's request.
  • Storage: sign-in tokens are stored only on the owner's computer. Mail content is not stored elsewhere or sold, and is not shared with anyone except the AI assistant the owner chooses to use.
  • Google user data use complies with the Google API Services User Data Policy, including the Limited Use requirements.
  • Revoking access: any account can remove access at myaccount.google.com → Security → Third-party apps.
